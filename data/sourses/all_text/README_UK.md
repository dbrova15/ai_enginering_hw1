# HardwareResearch AI — вибірка 200 статей

Цей архів містить 200 очищених текстів, відібраних для домашнього завдання курсу AI Engineering.

## Структура

- `texts/uk/` — 110 українськомовних текстів.
- `texts/en/` — 70 англомовних текстів.
- `texts/ru/` — 20 російськомовних текстів.
- `manifest.csv` — покажчик статей, мов, тем, оцінок, посилань та шляхів до TXT-файлів.
- `manifest.json` — той самий покажчик із контрольними сумами SHA-256.

Кожен файл `HR-XXXX.txt` містить *лише очищений текст статті* в UTF-8. Його ID відповідає ID у Google Sheets.
Тексти перенесені без перекладу чи редакторського перефразування з колонки «Чистий текст статті» основного корпусу.

Поля `score` та `category` відображають попередній автоматизований і частково перевірений відбір.
Поле `golden_set_candidate=true` лише рекомендує статтю для ручної розмітки: готових еталонних JSON-відповідей в архіві немає.
